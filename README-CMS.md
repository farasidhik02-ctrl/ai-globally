# AI Globally CMS build

## Local preview
1. Install Node.js (LTS).
2. In this folder run: `npm install`
3. Run: `npm start`
4. Open the local URL Eleventy prints.

## Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `_site`

## Publishing
Use Pages CMS. New articles are saved in `content/articles/`. Images uploaded in the article editor go to `assets/images/`. Eleventy automatically builds article pages, homepage sections, and the Latest Stories sidebar.
